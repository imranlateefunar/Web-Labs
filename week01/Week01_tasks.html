Class Activity B

8 min · URL teardown
Task

Break a real URL into its six parts

  1. Find any URL on the internet and copy the complete address.
  2. Split it into: Protocol, Host, Port (if any), Path, Query, Fragment.
  3. Make sure your URL contains all six parts — use a Live Server URL if needed to complete the set.
  4. Write each part separately.
  5. Change the product or search term, and check which part of the URL changes.
Answer:

URL: https://educareerinfo.free.nf:443/quizes/aror.php?quiz=5&cat=noncivil#ad

PartValue
Protocolhttps
Hosteducareerinfo.free.nf
Port443
Path/quizes/aror.php
Query?quiz=5&cat=noncivil
Fragment#ad

Changing the quiz number (e.g. quiz=1 → quiz=7) and Changing the quiz catagory (e.g. cat=noncivil → cat=civil) changes only the path. Changing the sort option changes only the query. Neither changes the host or protocol.

Class Activity C

5 min · HTTP Status Code Activity
Task

Capture one status code from each family

Open a website and open Developer Tools → Network. Find one status code from each family: 2xx Success, 3xx Redirection, 4xx Client Error, 5xx Server Error. Take a screenshot of each, and write the status code and its meaning below each screenshot.
Done when: you have one screenshot each for 2xx, 3xx, 4xx, and 5xx.
Model answer — where to find each one
  • 2xx Almost any successful page load — the main HTML document request is usually 200 OK.
  • 3xx Open https://http-stat.us/301 or https://http-stat.us/302, or visit a website that redirects (such as a shortened URL), and look for 301 Moved Permanently or 302 Found.
  • 4xx Visit any non-existent page on a real site, e.g. example.com/this-page-does-not-exist → 404 Not Found.
  • 5xx Harder to find on demand — some public "status code testing" endpoints intentionally return one (e.g. an endpoint documented to return 500), or note it the next time a site is genuinely down.

Class Activity F

10 min · Three DevTools Drills
Task

Network, Console, Elements — one drill each

  1. Network: reload. Find index.html. Confirm status 200. Screenshot it.
  2. Console: type document.title and press Enter. Check the result.
  3. Elements: double-click the <h1> text and change it. Reload — notice the file did not keep the DevTools edit.
Done when: you have a Network 200 screenshot, a one-sentence explanation, and you can say why the Elements edit disappeared.
Model answer

1. Network: the index.html row shows status 200, confirming the server (Live Server) sent the file successfully.

2. Console: typing document.title returns "Hello Web" — the exact text inside your <title> tag.

3. Elements: the heading change disappears on reload because Elements only edits the browser's live, in-memory DOM — it never writes back to the actual index.html file on disk.
